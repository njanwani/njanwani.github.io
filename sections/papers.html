A Learning-Based Framework for Safe Human-Robot Collaboration with Multiple Backup Control Barrier Functions
Neil Janwani, Ersin Daş, Thomas Touma, Skylar X. Wei, Tamas G. Molnar, Joel W. Burdick
ICRA, 2024
arXiv

Safety filters can be constructed using backup strategies, which restrict the robot to a set in which the backup strategy can always save the robot from danger. Even when the underlying safe set does not change, different backup strategies can result in safety filters that restrict certain behaviors, which can conflict with operator intention. In this work, we estimate operator intention using an LSTM-based network to safely select between multiple safety filters to satisfy operator intention, and successfully demonstrate our approach on hardware.
